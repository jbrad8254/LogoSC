# LogoSC Future Context

This compatibility file points to the project's living engineering notebook.

## Bootstrap for a new ChatGPT session

Read these files in this order before making changes:

1. `LogoSC-Developer-Notebook.md`
2. `README.md`
3. `CHANGELOG.md`
4. `LogoSC-User-Manual.md` and implementation notes as required

Then treat the newly uploaded repository ZIP as the sole source of truth and
ignore remembered files from older chats unless the user explicitly requests a
comparison.

`LogoSC-Developer-Notebook.md` supersedes this file as the primary handoff and
restart document. It preserves the historical contents of the original Future
Context file, along with design decisions, lessons learned, non-goals, roadmap,
workflow rules, and dated engineering history.

This small file remains so older bootstrap instructions and repository snapshots
that refer to `LogoSC-Future-Context.md` continue to lead to the correct document.
