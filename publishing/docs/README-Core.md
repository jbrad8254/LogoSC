# LogoSC Core

LogoSC Core is the complete stable LogoSC language for creating reusable 2D regions in OpenSCAD.
OpenSCAD remains responsible for extrusion, ordinary transforms and booleans, color, and final 3D
composition.

## Open this first

Open `LogoSC-Core-Examples.scad`, then select `Motif`, `Panel`, `Transformed`, or `Debug` in the
Customizer. Include `LogoSC-Foundation-Core.scad` from your own models.

## Documentation

- `LogoSC-Core-Guide.md` — Core-specific quick start and boundaries.
- `LogoSC-User-Manual.md` — complete language tutorial and reference.
- `LogoSC-CheatSheet.md` — compact command and public API reference.
- `LogoSC-Suite-Guide.md` — illustrated guide to all LogoSC suites.
- `LogoSC-Version.txt` — exact package source identity.

The ZIP is self-contained. Optional validation, knots, and fasteners are published separately.
