# LogoSC Nuts & Bolts

This self-contained suite provides a Customizer-driven printable fastener model with metric and
custom dimensions, several thread profiles, multiple heads and drives, nuts, bolts, screws,
assemblies, and selected-profile output.

## Open this first

Open `LogoSC-Nuts-And-Bolts.scad` and choose the part, size, thread, head, drive, and resolution in
OpenSCAD's Customizer. Read `LogoSC-Nuts-And-Bolts-Customizer.md` before changing calibration or
high-resolution export settings.

## Safety

Printed material examples and calculated dimensions are not structural ratings. Printer, material,
slicer, orientation, wear, fit, geometry, and loading all affect performance. Independently
validate every safety-relevant use.

## Documentation and verification
