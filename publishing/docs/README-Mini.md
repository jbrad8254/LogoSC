# LogoSC Mini

LogoSC Mini is the beginner-friendly edition of LogoSC, a Logo-inspired drawing language embedded
in OpenSCAD. It includes five progressive examples and the same compatible Core runtime used by
the larger suites.

## Open this first

Open `LogoSC-Mini-Examples.scad` in OpenSCAD and select an example in the Customizer.

## Included documentation

- `LogoSC-Mini-Guide.md` — five-minute introduction and learning path.
- `LogoSC-Mini-CheatSheet.md` — compact command signatures.
- `LogoSC-Suite-Guide.md` — illustrated guide to the complete LogoSC family.
- `LogoSC-Version.txt` — release, source state, repository, and issue location.

Keep the extracted files together. The package is self-contained.

## Source and support

LogoSC is maintained in one authoritative repository:
<https://github.com/jbrad8254/LogoSC>. Report durable bugs through its issue tracker.

See `LogoSC-Suite-Guide.md` for the project's concise development-provenance statement.
