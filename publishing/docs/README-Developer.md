# LogoSC Developer

LogoSC Developer packages the public engineering surface used to validate, test, diagnose, and
extend LogoSC. It includes the standalone Core, optional path validation, deterministic test
suites, engineering examples, command-line verification, and public design documents.

## Start here

1. Read `CONTRIBUTING.md`.
2. Open `LogoSC-Examples.scad` for Examples, Debug, and Tests modes.
3. Run `LogoSC-Foundation-Test-Runner.scad` for formal Foundation/Validation acceptance.
4. Follow `LogoSC-OpenSCAD-Command-Line.md` for reproducible console checks and exports.

## Documentation map

- `LogoSC-Development-Provenance.md` — substantial AI contribution, human direction, evidence,
  limitations, and contribution expectations.
- `LogoSC-Validation-Implementation.md` — path and topology validation design and test matrix.
- `LogoSC-ARC-Implementation.md`, `LogoSC-Holes-Implementation.md`, and
  `LogoSC-Transforms-Design.md` — focused implementation rationale.
- `LogoSC-User-Manual.md` and `LogoSC-CheatSheet.md` — public behavior.
- `LogoSC-Suite-Guide.md` — relationship to other publications.

AI Engineering Kit files, agent instructions, handoffs, and the mixed historical/bootstrap
Developer Notebook intentionally remain exclusive to the complete Git repository.
