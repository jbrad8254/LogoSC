# LogoSC 2026.7 — Celtic Grids and Multi-Suite Publishing

LogoSC 2026.7 expands Celtic-grid modeling and introduces the first synchronized publication
family for beginners, ordinary model authors, developers, knot makers, and fastener users.

The Core public API advances to `2026.7`. Existing opcode values, command syntax, coordinate
conventions, geometry behavior, and established public APIs remain backward compatible.

## Highlights

### Irregular and larger Celtic designs

- `"."` is now the canonical blank Celtic-grid cell.
- Rectangular string masks can describe irregular occupied regions, internal holes, diagonal
  contacts, and disconnected islands.
- Exposed occupied edges are traced into independent deterministic boundary loops without creating
  open strands.
- New large showcases include 8-, 16-, 24-, and 32-cell diamond/ring masks and a 37-by-9 mask
  spelling CELTIC.
- Advanced cycle discovery resumes after the previous visited state, substantially reducing large
  grid calculation time.

### Large-grid plaque output

The large Celtic showcase now supports:

- `Topology`
- `Cord`
- `Ribbon`
- `Plaque`

Plaque thickness, margin, corner radius, bevel, relief heights, and preview colors are
configurable. `Cord` remains the default so opening the showcase does not immediately request its
slowest output.

Large scenes print an early scene/output-specific duration estimate. LogoSC does not fabricate a
percentage-complete value because OpenSCAD provides no trustworthy model-level progress callback.

### Five synchronized downloads

Choose the smallest package that matches your goal:

| Package | Best for |
|---|---|
| `LogoSC-Mini-v2026.7.zip` | Learning LogoSC through five progressive examples |
| `LogoSC-Core-v2026.7.zip` | Writing complete LogoSC models with the stable standalone runtime |
| `LogoSC-Developer-v2026.7.zip` | Validation, automated tests, diagnostics, and implementation work |
| `LogoSC-Knots-Celtic-v2026.7.zip` | Knots, braids, Celtic grids, ribbons, reliefs, and plaques |
| `LogoSC-Nuts-Bolts-v2026.7.zip` | Customizable printable fasteners and thread profiles |

Every package is self-contained, carries the same Core version, includes an illustrated Suite
Guide, and identifies its exact source commit. There is no separate Full package: the complete
Git repository remains the authoritative full source, history, and bug-report location.

### Documentation and provenance

This release adds:

- a persistent Release Manual;
- an illustrated Suite Guide shared by every publication;
- package-specific READMEs and guides;
- reusable package manifests and verified ZIP tooling; and
- a public development-provenance statement.

LogoSC was developed primarily through a long-running, human-directed collaboration between its
maintainer and OpenAI AI coding assistants. AI assistance contributed substantially to design,
implementation, documentation, testing, and review. Project direction, acceptance, release
decisions, and stewardship remain under human control.
