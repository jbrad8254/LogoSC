# LogoSC 2026.8 — Procedural Systems and Accelerated Knotwork

LogoSC 2026.8 adds a backward-compatible local shear command, a complete optional L-system
companion in the source repository, several new generative-knot families, corrected crossing-safe
ribbon construction, and an optional C++/SVG path for practical large Celtic plaques.

The Core public API advances to `2026.8`. Existing opcode values, command syntax, coordinate
conventions, geometry behavior, and established public APIs remain backward compatible.

## Highlights

### Local shear and refreshed identity

- `[SHEAR, xFactor]` composes a local X shear through the ordinary evaluator, debug evaluator,
  tracing, state stack, affine conversion, tests, Cheat Sheet, and User Manual.
- The LogoSC wordmark keeps `Logo` upright and shears the complete multi-region `SC` suffix by
  `0.25`; the documentation wordmark and examples-gallery images were regenerated from source.

### Optional L-system companion

- `LogoSC-LSystems.scad` provides deterministic integer-symbol rewriting and LogoSC-command
  interpretation without adding Core opcodes.
- Nine presets cover Koch, quadratic Koch, Hilbert, Dragon, Sierpiński, Plant, Lévy C, Gosper,
  and Canopy systems.
- Seeded angle variation, printable open-path example geometry, a centered 3-by-3 gallery, public
  guidance, and an independent deterministic suite are included.
- L-system publication packaging is deliberately deferred. The companion remains available in
  the complete Git repository rather than adding a sixth synchronized download in this release.

### New generative knots and corrected crossings

- Lissajous, general planar harmonic, polar-rosette, and medial planar-graph generators produce
  validated sampled knot records with deterministic crossing information.
- Event-local traversal clipping cuts only the underpassing ribbon near each crossing and leaves
  the original over curve intact, eliminating the straight reconstruction artifacts exposed by
  dense rosettes.
- Alternating-parity solving, explicit graph-embedding validation, focused fixtures, printable
  plaque output, and generated galleries accompany the new generators.
- The Knot Customizer now groups galleries before individuals, orders both blocks by measured full
  preview time, and applies `*`, `**`, and `***` warnings from interactive cost on RAINBOW.

### Accelerated Celtic text and SVG workflow

- The dependency-free C++20 `logosc-knot-grid` tool converts text or existing ASCII masks into
  exact-size Celtic grids, validates and normalizes the plain `X`, `>`, `<`, and `.` format, and
  supports built-in or BDF bitmap fonts.
- The compiler builds indexed topology and emits compatible sampled `.scad` records plus
  pre-resolved closed-polygon SVG ribbon geometry.
- `FastSvgPlaque` imports that SVG through the accelerated printable path, while the committed
  C++/OpenSCAD parity fixture preserves an exact reference comparison.
- A 128-by-32 LogoSC stress design and progress indicators document the native OpenSCAD cost and
  the reason for keeping the accelerator optional.

### Scope closure

The planned `2026.8` generators are complete. General collision discovery, tight-curve rejection,
rectangular braid returns, random Celtic filling, custom boundary maps, unified polygon export,
decorative borders, bundled planar ribbons, direct STL/3MF compiler output, and automatic graph
planarization are explicitly deferred rather than silently remaining release work.

## Five synchronized downloads

The existing publication family remains unchanged:

| Package | Best for |
|---|---|
| `LogoSC-Mini-v2026.8.zip` | Learning LogoSC through focused examples |
| `LogoSC-Core-v2026.8.zip` | Writing models with the stable standalone runtime |
| `LogoSC-Developer-v2026.8.zip` | Validation, automated tests, diagnostics, and implementation work |
| `LogoSC-Knots-Celtic-v2026.8.zip` | Knots, braids, Celtic grids, ribbons, reliefs, and plaques |
| `LogoSC-Nuts-Bolts-v2026.8.zip` | Customizable printable fasteners and thread profiles |

Every package is built and tested from the same source commit. The complete Git repository remains
the authoritative source for optional companions and full engineering history.
