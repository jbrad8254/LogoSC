# LogoSC Core — A Logo-Inspired 2D Region Library for OpenSCAD

Write readable turtle commands and reusable motifs, then render them as closed 2D regions for
native OpenSCAD extrusion and composition. Core supports movement, arcs, primitives, repetition,
holes, multiple contours, affine command transforms, accessors, and preview-only debug output.

The download is self-contained and includes the standalone Core library, Core-only Customizer
examples, full user manual, cheat sheet, illustrated suite guide, and source-version record.
Validation, knots, and fasteners remain optional separate suites.

The download also includes `LogoSC-Core-Cover-Models.scad`, which turns all eight ideas shown in
the promotional cover into real, independently selectable models: a mixed-feature panel,
connected radial paddle fan, Koch-cutout plate, thickened Peano curve, tapered astroid sculpture,
slotted link, perforated ring, and curvy wire spool. Choose `All` to arrange the complete set on
one build plate. All models are based at `Z=0` for printing.
