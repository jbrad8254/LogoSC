# LogoSC Developer — Validation, Tests, and Engineering Documentation

The Developer suite is for people who want to inspect, validate, test, diagnose, or extend LogoSC.
It adds explicit path validation, deterministic Foundation/Validation tests, direct test runners,
debug examples, command-line verification, contribution guidance, and implementation documents to
the stable Core runtime.

It also includes the public development-provenance statement describing LogoSC's substantial AI
contribution, human direction, verification evidence, and limitations. Internal AI handoff and
agent-workflow files remain in the complete Git repository rather than this package.

Authoritative source, complete history, and issues:
<https://github.com/jbrad8254/LogoSC>

LogoSC was developed through sustained human-directed collaboration with OpenAI AI coding
assistants; project direction, verification, and releases remain under human control.
