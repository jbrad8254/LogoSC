# LogoSC Mini — Learn Turtle CAD in OpenSCAD

LogoSC Mini turns short Logo-style movement commands into real OpenSCAD geometry. The download
includes five progressive Customizer examples: a triangle, flower, badge, mounting plate, and
printable token.

Extract the ZIP, open `LogoSC-Mini-Examples.scad`, choose an example, and preview. The included
five-minute guide and compact command card teach movement, turns, arcs, repetition, primitives,
holes, and extrusion without requiring the complete developer toolset.

Mini uses the same compatible LogoSC Core runtime as every larger suite, so a first command list
can grow into a complete model without changing dialects.

Complete source, documentation, and bug reports:
<https://github.com/jbrad8254/LogoSC>

LogoSC was developed through sustained human-directed collaboration with OpenAI AI coding
assistants; project direction, verification, and releases remain under human control.
