# LogoSC Mini — Learn Turtle CAD in OpenSCAD

LogoSC Mini turns short Logo-style movement commands into real OpenSCAD geometry. The download
includes five progressive Customizer examples: a triangle, flower, badge, mounting plate, and
printable token.

The download also includes `LogoSC-Mini-Cover-Models.scad`, which turns all eight ideas shown in
the promotional cover into real, independently selectable models: a rounded mounting plate,
triangle plaque, perforated ring, eight-petal flower, plain washer, eight-lobed rotor, capsule
token, and thick washer. Choose `All` to place the complete set on one build plate.

Extract the ZIP, open `LogoSC-Mini-Examples.scad`, choose an example, and preview. The included
five-minute guide and compact command card teach movement, turns, arcs, repetition, primitives,
holes, and extrusion without requiring the complete developer toolset.

Mini uses the same compatible LogoSC Core runtime as every larger suite, so a first command list
can grow into a complete model without changing dialects.

## How I Designed This

I created LogoSC because I needed an easy, programmatic way to generate reusable 2D geometry in
OpenSCAD—first for thread profiles used in customizable nuts and bolts, and then for badges,
plaques, knots, and other extruded objects. My goal was to create an exceptionally well-tested,
stable platform on which more complicated 3D objects could be built with OpenSCAD. The project
grew through a long-running collaboration between me and OpenAI's AI coding assistants: I proposed
goals, tested results, challenged designs, and made the final decisions, while the AI explored
algorithms, implemented ideas, documented behavior, and suggested improvements. Much of LogoSC
emerged from that back-and-forth process of experimenting, inspecting the actual geometry, finding
failures, and refining the code together. This download is the basic version; other LogoSC
distributions provide more advanced modeling features, validation and testing tools, Celtic knots
and plaques, and customizable nuts and bolts.
